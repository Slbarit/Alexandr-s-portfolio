# Портфолио — Александр Брей

Статический сайт из четырёх HTML-файлов. Внешних зависимостей нет, кроме шрифтов Google Fonts.

- `index.html` — главная со списком кейсов
- `case-dashboard.html` — «Четырнадцать колонок»
- `case-elety.html` — «Семь интервью»
- `case-novalab.html` — «Цена одной школы»

## Как опубликовать на GitHub Pages

1. Зарегистрироваться на github.com
2. Создать публичный репозиторий с именем `portfolio`
3. Загрузить все файлы из этой папки в корень репозитория (кнопка «Add file» → «Upload files»)
4. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, папка `/ (root)` → Save
5. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/portfolio/`

Этот адрес и ставится в резюме.
